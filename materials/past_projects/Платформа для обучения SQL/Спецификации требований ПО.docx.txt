Запрос на изменение
Документ процесса УК ПО, созданный для внесения изменений в данные ЖЦ ПО с целью устранения несоответствия, описанного в СП.

Атомарное данное ЖЦ ПО. Артефактом может быть, например, требование или файл исходного кода.
Конфигурация
Составное данное ЖЦ ПО, которое может включать в себя любые артефакты, агрегации и конфигурации.

Совокупность всех требований, предъявляемых к программному обеспечению, и дополнительных сведений, необходимых для правильной интерпретации этих требований. Спецификация требований организована как агрегация в.

Таблица 3. Требования к процессу регистрации
Идентификационный номер
Требование
1-01-FE-001
Форма регистрации должна содержать следующие поля для ввода данных:
	•	Поле для ввода:  Ваше имя (1.1.1)
	•	Поле для ввода: Ваша Фамилия (1.1.2)
	•	Поле для ввода: Логин (1.1.3)
	•	Поле для ввода: Email (1.1.4)
	•	Поле для ввода: Пароль (1.1.5)
	•	Поле для ввода: Повторение пароля (1.1.6)
	•	Флаг: Я администратор (1.1.7)
1-01-BE-002
Введенные в форме регистрации данные должны проверяться инструментами валидации на соответствие следующим условиям: 
	•	Отсутствие запрещенных символов в полях 1.1.1  и 1.1.2 (только кириллица)
	•	Данные в поле 1.1.5 должны соответствовать шаблонам написания электронной почты
	•	Данные в полях 1.1.5 и 1.1.6 должны совпадать
	•	Данные в поле 1.1.3 не должны были использоваться ранее
1-01-FE-003
Страница регистрации должна содержать кнопку для регистрации нового пользователя ( 1.1.8) 
1-02-BE-004
Информация из формы регистрации должна сохраняться в базе данных, отправляется соответствующий запрос на изменение БД
1-02-BE-005
После успешного создания учетной записи на указанный адрес электронной почты  должно отправляться автоматического уведомления, содержащее ссылку для подтверждения адреса электронной почты.
1-02-BE-006
После перехода по ссылке для подтверждения адреса электронной
почты открывается соответствующая страница с профилем -
пользовательский профиль (интерфейс 3.1) 
1-03-BE-007
В случае наличия флага администратора (1.1.7) система должна предоставлять пользователю права администратора в соответствии с функционалом ролей после ручного рассмотрения заявки на создание учетной записи

В случае изменений в полях и при нажатии на кнопку “Сохранить “ (3.1.5) в БД отправляется соответствующий запрос на изменение данных

Идентификационный номер
Требование
5-01-FE-001
Страница каталога должна обладать следующими полями для поиска:
	•	Поле для поиска по названию (5.1.1 / 5.2.1)
	•	Список тегов (5.1.2 / 5.2.2)

Система должна отображать на экране все курсы (интерфейс 5.1.) или задачи (интерфейс 5.2.), которые получены в результате запроса в БД на поиск по параметрам

5-01-BE-006
При нажатии на кнопки вида 5.1.4 в интерфейсе 5.1  должна открываться страница соответствующего мини-курса 
5-02-BE-007
При нажатии на кнопки “Решать” (5.2.4) в интерфейсе 5.1 должна открываться страница решения соответствующей задачи

7-02-BE–007
