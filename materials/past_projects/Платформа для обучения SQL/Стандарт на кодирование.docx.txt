Она обеспечивает ORM (Object-Relational Mapping) — технологию, позволяющую взаимодействовать с базой данных, используя объектно-ориентированный подход, а не традиционные SQL-запросы.
Ссылка на официальный сайт: https://docs.sqlalchemy.org/en/20
	•	Стандарт на форму представления исходного кода
Для форматирования и стиля написания исходного кода на языке Python существует PEP 8 (Python Enhancement Proposal 8). PEP 8 представляет собой официальный документ, в котором описаны рекомендации по стилю кодирования для проектов на языке Python. PEP 8 является стандартом для стиля кодирования на языке Python, и его рекомендации помогают обеспечить читаемость и согласованность кода в сообществе Python. Рекомендуется следовать PEP 8 при написании кода на Python для поддержания стандартов и улучшения сопровождаемости проектов.
Ссылка на официальный сайт: https://peps.python.org/pep-0008/ 

	•	Правила именования компонентов, подпрограмм, переменных и констант 
	•	Все переменные и методы именуются с помощью snake_case.
	•	Константы именуют только с использованием верхнего регистра и подчеркивания для связи слов CUP_WITH_UNDER.
	•	Все названия объектов, классов и интерфейсов записываются с использованием UpperCamelCase.
	•	Пакеты именуются нижним регистром с использованием подчеркивания для связи слов com.xxx.sql_course.
	•	Используются настройки редактора кода по умолчанию: четырехсимвольные отступы, табуляции как пробелы.
	•	Используется хотя бы одна пустая строка между определениями методов, полей и определений.

Ограничений на применение инструментов не принимаются.
